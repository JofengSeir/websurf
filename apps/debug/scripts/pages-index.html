关于 Ctrl + W：页面被关掉不是闪退

浏览器里 Ctrl + W 就是「关闭当前标签页」。本项目的默认蹲键也是 Ctrl，所以「蹲下 + 前进」时很容易顺手把页面关掉 —— 这不是闪退，也不是项目缺陷，是浏览器快捷键抢占。

想彻底避免，下面两种方式任选其一：

  1. 改游戏内键位（推荐，不用装任何东西）：进入页面后按 ESC 打开面板 → 按键 → 把「蹲」从 Ctrl 改绑到别的键（例如 Shift）。改完 Ctrl + W 自然就不会再触发。
  2. 装浏览器扩展，把 Ctrl + W 改掉：安装 More Better Ctrl-W， 然后在地址栏打开 chrome://extensions/shortcuts，找到该扩展的 Do absolutely nothing 一项，把它设为 Ctrl + W。 此后 Ctrl + W 不再关闭页面。
    代价：这一改法会让「先按 Ctrl 蹲、再按 W 前进」 这个组合被阻断 1 秒以上（「先按 W 前进、再按 Ctrl 蹲」不受影响）。若你习惯先蹲后走， 用上面第 1 种方式改键位更合适。

注意：录快捷键时，输入框里直接按 Ctrl + W 可能当场把设置页也一起关掉；若被占用录不进去，可试着先按 W 再按 Ctrl。
