鼠标与键盘

点击画面锁定鼠标后自由飞行：WASD 平移、空格/C 升降、Shift 加速（×4）、Esc 解锁。

录像回放：K 播放 / 暂停，, / . 逐帧，I / O 设区间 A / B。输入框内这些键不生效。

载入地图与录像

地图：引导层按钮；加载后地图页顶部「更换地图」；或把 .bsp 拖进窗口（换图会重建场景）。录像：录像页「选择录像文件…」、拖入 .replay（自动切到录像页）；URL 深链 ?bsp=&replay= 可直接打开配套资源。导入后底部显示「录像信息条」——.replay 头部元信息：成绩 / 玩家 / 地图 / 轨道 / tick / 帧段 / 日期。

播放基准与坐标映射

录像以 .replay 帧自身坐标播放（默认直读，无起点锚定）。轨迹与地图对不上时用录像页「坐标映射」切换对照（轴序 / 朝向轴），仍差一点用「调整工具」显式平移 / 旋转 yaw。时间轴以起跑帧为 0（prerun 帧不在播放区间）；进度条淡蓝带 = 正式跑段、金色框 = A-B 区间。外部脚本可经 window.viewer.replay 控制播放：play / pause / seek(秒) / setSpeed / setMode / follow / tracks() / meta()。
