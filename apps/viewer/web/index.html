鼠标与键盘

点击画面锁定鼠标后自由飞行：W/S 沿视线前进后退（朝上看就往上飞）、A/D 水平平移、Q/E 原地转向、Shift 加速（×4）、Esc 解锁。

记录回放：K 播放 / 暂停，, / . 逐帧，I / O 设区间 A / B。输入框内这些键不生效。

载入地图与记录 / 录像

地图：引导层按钮；加载后地图页顶部「更换地图」；或把 .bsp 拖进窗口（换图会重建场景）。记录 / 录像：引导层「导入记录 / 录像」、记录页「选择记录文件…」（只收 .replay）、录像页「载入录像（.dem）」、或直接把文件拖进窗口 —— 四种入口都按**文件内容**分派，误选也会自动切到对应页面；URL 深链 ?bsp=&replay= 可直接打开配套资源。导入后底部显示「记录信息条」——.replay 头部元信息：成绩 / 玩家 / 地图 / 轨道 / tick / 帧段 / 日期；载入录像则显示「录像信息条」——.dem 独有事实：服务器 / 天空盒 / 协议 / 时长 / 事件 / 实体流规模 / 字符串表 / 包走读（逐项的诊断细节在悬停提示里）。

播放基准与坐标映射

记录以 .replay 帧自身坐标播放（默认直读，无起点锚定）。轨迹与地图对不上时用记录页「坐标映射」切换对照（轴序 / 朝向轴），仍差一点用「调整工具」显式平移 / 旋转 yaw。时间轴以起跑帧为 0（prerun 帧不在播放区间）；进度条淡金带 = 正式跑段、金框 = A-B 区间。外部脚本可经 window.viewer.replay 控制播放：play / pause / seek(秒) / setSpeed / setMode / follow / tracks() / meta()。
