提示

蹲下时别顺手按 W：那会关掉标签页

浏览器把 Ctrl + W 定义成「关闭当前标签页」，而本项目的默认蹲键也是 Ctrl。于是「蹲下 + 前进」很容易把页面一起关掉。

这不是闪退，也不是缺陷——是浏览器快捷键抢占。三个站点都注册了离开确认，关闭 / 刷新前会先问一句，选「取消」就能留下。

01
改游戏内键位（推荐，不用装东西）

进入页面后按 ESC 打开面板 → 按键 → 把「蹲」从 Ctrl 改绑到别的键（例如 Shift）。改完自然就不会再触发。

02
装扩展，把 Ctrl + W 接管掉

安装 More Better Ctrl-W， 再打开 chrome://extensions/shortcuts，把该扩展的 Do absolutely nothing 设为 Ctrl + W。

代价：这一改法会阻断「先 Ctrl 蹲、再 W 前进」1 秒以上（先 W 再 Ctrl 不受影响）。习惯先蹲后走的话，用第 01 条更合适。

录快捷键时在输入框里直接按 Ctrl + W 可能当场把设置页一起关掉；录不进去就先按 W 再按 Ctrl。
