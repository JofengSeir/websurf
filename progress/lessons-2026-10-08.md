## 2. 查实的技术事实（可复跑）

### 2.1 碰撞生成
- **brush 只看 `contents`**：`BuildWorldPhysModel` 用 `MASK_SOLID`/`CONTENTS_PLAYERCLIP`/`CONTENTS_MONSTERCLIP` 三个掩码；`CPlaneList::ReferenceBrush` 只按 `contents & mask` 取舍——**纹理、可见性都不参与**（`BuildConvexForBrush` 只跳 `pside->bevel`，不可见面仅不 shrink）。这就是 T-447 的根因：模型坡的 playerclip 楔形贴的是 `TOOLS/TOOLSSKYBOX`，我们按纹理整批丢了。
- **置换面碰撞**：`Disp_AddCollisionModels(..., MASK_SOLID)`，逐面 `if (!(contents & mask)) continue;`；`contents` 继承基面 brush（无可见/CLIP 内容时 `|= CONTENTS_SOLID`）。8 张图实测 0 例会被跳过。
- **静态道具**：`m_Solid` 0 = 不进碰撞树不建 vphysics、2 = bbox、6 = `.phy`（`solid=0` 的 1483 个装饰道具在原版也是可穿的 ⇒ D-018）。
- **三角形障碍集**：`clip_box_to_triangle` 必须是"三角形 ⊕ 盒"的完整 Minkowski 面集（2×±n + 9×cross(edge,axis) + 6×盒轴），少一面就会从棱线穿过去（T-445）；三角形**不写** `start_solid`/`all_solid`（T-444）。

### 2.2 置换面（位移面）细分
- 引擎是**四叉树 + 每节点 8 点扇**（`g_TesselateWinding` 9 项环绕表，末项收口），叶层每扇 8 个三角形；非叶节点在 4 个子节点全活时**不出三角形**；`m_AllowedVerts`（`ddispinfo_t` 偏移 136，10 个 u32）控制环绕点与子节点参与。
- `CDispVert` = 20 字节（vector 12 + dist 4 + alpha 4），**vector 是单位方向、dist 是距离**；数组展平顺序是 `flat = x*side + y`。
- **转置 bug 的隐蔽性**：顶点位置本身正确（光照 UV、混合权重都自洽），只是三角形**连错顶点** ⇒ 肉眼只看到"地表位置不对"，不会想到是拓扑。判据必须落到拓扑（网格三元组），不能只看位置。

### 2.3 光照与材质
- 雪盖在 `WorldVertexTransition` 的 `$basetexture2`，混合系数是**位移顶点的 alpha**（不是 `LUMP_DISP_LIGHTMAP_ALPHAS`，boreas 里 0 字节）；`_VBSP_BLEND` 自定义属性 + 第二贴图走材质 extras。
- 位移面的 lightmap UV 必须走**细分网格单位方格**，不能用投影（投影会漂出本面，实测 68.9% 越界）。
- VHV 顶点序要按 SDK 重排 strip group 序到模型顶点序（T-437）；退化 VHV 退回 leaf ambient cube（T-438）；ambient cube 的方向随位置转轴（T-435）；γ 的输出编码漏一处就整体偏暗（T-423）。

### 2.4 天空盒与雾
- 轴约定：世界顶点写 `[y,z,x]` ⇒ Three 轴 = (X←SourceY, Y←SourceZ, Z←SourceX)；六面槽位 ft→pz / bk→nz / lf→px / rt→nx / up→py / dn→ny，极面要面内旋转。
- 3D 天空盒用**起源第二相机两遍法**（不是复制几何）；`sky_camera` 的微缩外景必须**绕相机缩放**（锚点取世界原点会整体错位）；天空遍的雾取 `sky_camera` 自己的参数、start/end 乘 `1/scale`（`Enable3dSkyboxFog`）。
- 2D 天空盒是背景；两遍法第二遍必须**摘掉背景**，否则 three 的背景 pass 会盖掉天空遍。

### 2.5 三工程分工
- 共享层（`src/wasm-core`/`renderer-shared`/`ts-shared`/`phys`）是同一份，各工程缺的是**接线**；viewer 薄导出层**只加解析层导出**（`parse_pvs_data` 这类），**不引 `websurf-phys`**。
- 查"某功能是否已接上"最快的办法：字段/marker 矩阵 + 三工程 wasm 产物时间对比共享层最新改动。

## 3. 工程与流程纪律（本仓特有）

1. **锚点纪律**：给带锚点的文件加行会让行号变旧，而 `docflow sync` 只按行号重钉内容 ⇒ 优先把改动压成 **1:1 行替换**；必须加行时先按 `git diff -U0` 的 hunk 平移文档里的行号再 sync。加 `#[wasm_bindgen]` 导出优先在文件末尾追加独立 impl 块。
2. **认领契约**：`docflow claim --task T-xxx --must … --may …`；先改后认领会失败 ⇒ 备份 must 文件 → 还原 HEAD → release+claim → 还原备份 → `verify`。
3. **看板体量**：硬上限 96 KB；超了先"逐行精简"（长判据转 `见详情`），再考虑「已记录+已结案」分卷（**分卷要先取 owner 许可**，见 D-020）。
4. **progress 分卷**：写哪一卷以 `progress/index.md` 的「当前写入目标」为准；每卷 ≤ 40 KB（硬 48 KB），新卷要补上/下卷链接 + 登记 + 索引一行。
5. **只读 md**（`documents/norms/**`、根 `README` 等）不得直接改；连"锚点平移"波及它也要用不改行数的写法规避。
6. **提交前先 `git status --short`**：本仓常有并发 agent，只 add 自己改的文件。

## 4. 环境陷阱（本机实测）

- 本机**无 Chrome**：需要浏览器的门（archify finalize / smoke）先设 `ARCHIFY_CHROME=…msedge.exe`，否则只会 skipped。
- 访问 GitHub 走 Clash：`HTTPS_PROXY=http://127.0.0.1:7897`（7890/7891 未开）；`web_fetch` 直连会超时，用 `pwsh` 的 `Invoke-WebRequest -Proxy`。
- 沙箱：`run_code`/`pwsh` 起的 Node 子进程写 `.tmp` 可能裸 EPERM；docflow / check-doc-drift / 认领需要 danger-full-access。
- `cargo test/check -p websurf-wasm-core` 在**宿主目标**跑不了（缺 dlltool）⇒ 验 wasm-core 改动只能"重建 wasm + `.tmp` 探针"。
- PowerShell 5.1：无 `&&`；`try{…}catch{}` 不能挤成一行（会报 "missing Catch"）。
- Python 输出中文要 `PYTHONIOENCODING=utf-8`，且避免在 print 里用箭头符号。

## 5. 事故与教训

| 事故 | 教训 |
|---|---|
| 一次"锚点平移"把只读 `README.md` 改到需审批 | 只读文件的锚点要用**不改行数**的写法规避；改不动就先改设计 |
| `TODO.md` 单元格里写了裸 `\|` | 表格解析器不认转义 ⇒ 单元格内一律不用竖线（用 `+`） |
| 13 处锚点被 `sync` 钉成错误内容 | `sync` 只重钉内容、不校验行号 ⇒ 加行前先平移行号 |
| `prps` 块解析出垃圾 | game lump 的块也是 LZMA 压缩 |
| 模型名对不上 | 模型下标是 `m_PropType`（offset 24），不是 offset 26 |
| 置换面三角形连错顶点 | 最难发现的一类：位置对、拓扑错 ⇒ 判据要落到拓扑 |
| 全历史脱敏重写 | 重写前的所有 SHA 失效，文档里的旧引用不可解析 |
