## 5. 执行中的更正（如实）

- **C7 前提被推翻**：任务书写「统一 CRLF」，实测本仓 `core.autocrlf=true` 且无 `.gitattributes` ⇒ 规范形式是 **LF**（索引 326 个文本文件仅 2 个带 CR）。真问题是那 2 个文件各含**一个裸 CR**（恰好占掉字母 `r` 的位置，使 git 判 `-text`、autocrlf 长期跳过）——已修复并加 `[F]` 门。
- **`[E]` 自身缺陷**：该门最初被写在 `found` 循环体内，不含锚点的行整段漏检；闭环实证（注入坏链）时抓出并修正。
- **任务书 §9 三项**（注释全量收口 / 界内错位锚点复核 / 体检内容级抽样）：owner 指示**忽略不做**。
