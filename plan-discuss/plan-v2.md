## 1. 方案 v2：共识设计（每条注明依据）

### 1.1 形态一句话

**新增 `tick` 计算模式（additive）：worker 单 PhysWorld 实例、raw 64Hz 固定 tick、零校准零锚定零第二实例；主线程零物理实例、纯历史插值消费（确定性 tick 网格 α + 弦插值 + 直出兜底）；渲染值全部来自已算出的 tick 状态，α∈[0,1) 一票否决外推。**
依据：t3 §2/§3（架构与消费）、t4 §1（验收定义）、t1 §0.4（可行性判定）、用户前提①②③④。

**忠实性判定基准（采纳研究员 §1.4 分界判据，t5 定稿；§9.3 升级三分判据）**：
- **A 类**＝单实例可复现 ∧ **语义定义性**（tick 网格定义 / CS 谱系公式逐字复刻 / 用户自定义常量）→ 保留、白名单化；
- **B 类**＝单实例构造上不可复现 → 消除（v2 删双实例+校准写入通道）；
- **C 类（新）**＝单实例可复现 ∧ **数值面**（ε 家族 / start-inside pushout / MAX_CLIP_PLANES 槽位竞争 / 扫掠漏检候选）→ **内核缺陷候选：不冻结为语义、不误归 B**；处置＝下一团队修内核 + 回归测试（p2_gate_tests.rs 先例扩展）+ gate_veto_count 噪声指标监控。
A1–A9 二次检验终局：A1/A2（含双钳不对称）/A3/A5/A6/A7/A8（常数绑 tick 数，64t 下 93.75ms 即语义）/A9 **全部通过**；**A4 拆分**：A4a＝clip_velocity 接触剪裁 + overbounce 1.0/1.001（PL:323-345）＝语义保留；**A4b＝原「先穿入 ≤|v_n|/64 再 clip」表述错误**——扫掠把位置停在首接触点（end_pos+PUSH_OUT），**位置从不真正进入体内**，≤0.6u 是「若无剪裁将会穿入的假想量」；薄沿×大速度**不放大成真穿透**（见 §1.5 扫掠判定）。该判据同时是五维对比「忠实性/边缘行为」维度的定义与 G4 关校准轴的预期判形。依据：t1 §1.4 + §9.3 + t4 §5.3 + t3 §5.1。
**substep 地位**：默认关（任何 tick 内细分把 64 边形变 N·64 边形，改写洞见④金标准语义）——存档为穿透对策备胎，启用与否走 §1.5 坍缩条款与用户裁决 U3。依据：t3 §5 + t4 §5.1。

### 1.2 worker 侧（几乎零新代码）

1. **复用 auth-loop 现成引擎**（`auth-loop.ts:123-201`）：4ms 自驱 + 固定步长累积器（guard 64）+ takeInput → tick → writeAuthoritative。tick 模式增量 = gate 谓词三值 + `setFixedDt(1/64)` raw + 每 tick 发布 + 断点标记。依据：t3 §0.1/§2.1。
2. **删除清单（B1–B8 对应面，t1 §1.3 + t3 §7 #1–7 双重锚定）**：主线程 predPhys 及其六步消费、calibrateVelocity、applyCollisionCorrection 吸附、反向同步 sync-render-state、撤回兜底、tickPhys 第二实例、set_velocity 速度注入、TICK_ANCHOR_DIST 锚定拉回、激活边沿对齐、解耦背压/慢字段缓存。耦合/解耦分支代码逐行不动（分支只增不改），gate 谓词扩展是唯一触点。依据：t3 §6 共存矩阵。
3. **事件出口**：teleport/death 走既有 worker 消息（mod.rs:261 take_event 单次语义）；land/blocked 在 tick 模式停发（无校准消费点；遥测改由消费侧 starvation/T 表承担）。依据：t3 §6 表。
4. **hold 冻结**：worker 侧 additive holdState 顶置检查（v1.1 补设计——耦合的主线程逐帧 set_state 与解耦的 runHeldRound 在 tick 模式均不可用）。依据：t3 §4.6。
5. **调度档位（延迟可压缩项，唯一）**：缺省 setTimeout(4)（ε≤8ms，Δ≈T+guard）；可选 Atomics.wait(输入槽, timeout=距下个 due tick) 精确唤醒（ε<1ms，Δ≈16.6ms）——0ms 急轮询先例 `decoupled-loop.ts:301`。依据：t4 §1.3 修正推导 + t3 §3.1.1 + t2 双工作点。

### 1.3 消费侧（P0 逐帧等式为骨架）

1. **发布面**：每 tick 写 B_A 十值 + `I_A_FLAG`（i32[5]，断点/段起标记）+ `I_A_TICK`（i32[6]，tickIndex）；字节 20–63 保留区空闲（B_DX_ACC 在 i64[8]=字节 64 起，亲核）。MsgState 回退路径同载荷双喂。依据：t3 §2.5 + t4 §5.1 裁定（三方合一：t1 BC2 段序号 = t3 FLAG = t4 TICK）。
2. **P0 等式**：τ_display = max(τ_prev, now − anchor − Δ)；确定性网格 α（t_k = T0 + k·T，T0_est=EMA(W_k − k·T)，残差不进 α）；pos/yaw(最短弧)/pitch/eyeHeight 弦插值；容差 1e−3 HU / 1e−3°；α<1+1e−9 一票否决。依据：t4 §1.1 + t3 §3.1.1（v1.2 已全盘采纳网格 α，实测间隔方案作废）。
3. **消费侧硬不变量 4 条**（全部进 Gate 2 断言）：显示时间单调性（防 D+=1ms 的 ~3.5 HU 倒退跳变）；跨线程时钟锚（一次性 + 漂移刷新，`extrapClockAnchorMs` 先例）；光标跳变白名单 + 遥测（重锚/快进/断点直出逐次计数，D 有界披露）；断点帧禁跨界插值（八类断窗清单 + deathY/substep 双补判 + |Δpos|>100u 几何兜底默认关）。依据：t4 §5.1 + t3 §3.4/§3.4.1。
4. **兜底**：冻结最后真实帧 + starvation 计数——**红线：任何代码路径不得引入任何外推（哪怕 1ms）**；P-tick-2 凸组合断言对全路径（含兜底/重锚/断点帧）逐帧成立。依据：t3 §3.5 红线声明（v1.1 落实）。
5. **延迟预算（统一口径，三方收敛；t1 §9.3 补口径区分防漂移）**：固有呈现延迟 = tick 对齐（≤1T，均值 0.5T）+ Δ（T+guard；setTimeout 档 Δ≈19.6–24ms，Atomics.wait 档 Δ≈16.6ms）+ 合成一帧（≈7ms@144Hz）。**两口径并行（引用时必选其一）**：**状态→光子（显示新鲜度）**= Δ+合成 ≈ **31ms（setTimeout 档）/ 23.6ms（Atomics 档）**——研究员 BC1 口径；**输入→光子（手感，r3 用户问题的正确口径）**= 输入对齐 + Δ + 合成 ≈ **38.8ms（setTimeout）/ 31.4ms（Atomics）**——本文五维表与 r3 问答用此口径。rAF 频率不影响 Δ 下界（只影响弦采样粒度）。依据：t3 §3.6 表 + t4 §1.3 修正推导 + t2 延迟列 + t1 §9.3。**分量表钉死（t6 末对账；研究员+reviewer 联合结论，mode-designer 36/43 vs 31.4/38.8 之差=scanout 计否）**：输入→光子 = ①输入对齐 0.5T≈7.8（均值，≤1T 最坏）+ ②Δ=T+guard（Atomics 16.6 / setTimeout 19.6–24）+ ③合成一帧 ≈7@144Hz + ④**scanout ≈4–5ms（可选口径）**——mode-designer v1.3 的 36/43=**含 scanout**，本文 31.4/38.8=**不含**；引用任何延迟数字必标注 scanout 计否。
6. **平滑效果（勘误后口径）**：3500 u/s @144Hz 每 rAF 位移 = **24.3u**（3500/144；t4 早期稿 8.5u 为口径错误，已由 t3 勘误并经复核确认）；64 边形顶点全保真，弦差 = |a|·T²/8（重力 0.024u / air-accel 极端 1.14u，实测上界 <1.5u）。依据：t3 §3.2/§3.3 + 勘误记录。
7. **存点/HUD 分源（已裁定 PASS 附两条件）**：存点 = F_latest 物理真值（插值态恢复会把弦中间点注入为新顶点原点，破坏 64t 语义）；HUD = 插值态（凸包内合规）；restore 必须走断点帧路径；向用户披露存点瞬间 saw-vs-stored ≤ 半弦（3500u/s 时 ≤27.4u）与 HUD 速度半 tick 增量差。依据：t4 §5.1 D7 裁定 + t3 §6 表。

### 1.4 参数单写链（结构性消灭 W-GAP-1 类 bug）

面板 → bridge.sendConfig → worker config 分支 → normalizeConfigPatchKeys → applyConfigPatch → phys.set_params → 下一 tick 即用。主线程无实例、无第二写路；交接/hold/respawn/teleport 路径零参数触碰（t3 §4.5 七行调用点 grep 实测）；review 不变式：上述路径禁新增 set_params。tick 原子性：worker 单线程事件循环让出窗口处理 config → 参数生效点天然落在 tick 之间，无单 tick 撕裂态。「完美生效」四判据：生效延迟 ≤1 tick / 零平滑尾迹 / 值语义精确（W-GAP-1 消除）/ 速率变化零状态跳变。依据：t3 §4。
**tickRate 语义**：`getConfigTickRate()` tick 分支 **raw 直译（64 就是 64）**；耦合线 +3 偏移（`worker/main.ts:53` TICK_RATE_OFFSET=3）不渗入；Gate 2 断言 fixedDt === 1/64 精确成立。依据：t3 D1 + t4 §5.2 + 研究员 BC6（三方一致，用户收尾）。

### 1.5 substep 地位（研究员世界线判定：撤下，非默认关）

1. **扫掠精确性结构判定（t1 §9.3，读 world.rs 后可写死）**：brush 与 triangle 共用同一 `clip_planes` 核心（world.rs:159-243）——Minkowski 盒扫掠的平面裁剪；triangle＝双面面平面（:296-299）+3 条质心校验边平面（:301-318）＝凸棱柱半空间交集。对凸体这是**步长无关的一阶接触精确检测**：进入分数是闭式计算（(d1−ε)/(d1−d2)），不是离散采样——**54.7u 步对 16u 薄沿在数学上不可能穿薄**（扫掠体积区间测试与步长无关）。幻影的唯一算法源＝有限面的无限平面外插 → **P2 门已治愈**（aabb_overlaps_at :136-155；soundness 论证自含 :120-134）——P2 门的存在不是「TriMesh 扫掠有洞」的证据，而是「无限平面表示有洞且已补」的证据。残余数值面＝ε 家族（DIST_EPSILON=0.03125 绝对量不随步长缩放、进入分数烘焙 −ε、悬停噪声守卫、门 EPS=ε/8）误差有界 ~ε 且与步长无关；start-inside 分支（:220-234 + PL:848-872）独立于步长。
2. **裁决（覆盖此前「默认关+存档备胎」表述）**：扫掠精确 ⇒ **substep 无正确性存在理由——从 v2 候选清单撤下**；任何 tick 内细分把 64 边形变 N·64 边形（改写洞见④金标准语义），它唯一能改变的是事件相位＝改写物理＝改语义。C 类对策的正当性辩护不成立——**不存在需要 substep 对策的 C 类穿透**。用户 r3 裁定「授权 C-2 自决」覆盖本精化：自决判据升级为下条。
3. **推翻钩子（几何接触集恒等式，同时是 D2 最终裁决者，交 bench-planner）**：固定速度直线入射、零输入脚本下，GOLD 与 FINE 的「被接触面集合」应逐面一致（相位差 ≤1 tick＝A 类）；**FINE 检出而 GOLD 漏检的面＝扫掠漏检 C 证据**——实验一旦证实，本判定推翻、substep 回到 C 类对策候选。附 P-sub-1..4 命题存档（输入采样不变式/算子顺序不变式/一阶总量守恒+收敛性/断窗无关）。依据：t1 §9.3 + t3 §5.3 + t2 G3 sweep 轴。

1. **架构面结论（t3 §5.1，已被 §1.5.1 世界线判定覆盖并升级）**：扫掠对直线段精确 ⇒ 薄沿穿透不因速度发生；真实高速风险是**弧入弦差** ≈ (v·T)²/(8R)：3500u/s、R=64u → 5.9u（注：研究员 §9.3 修正——A4 的 0.6u 非位置穿透，是假想剪裁缺省穿入量；弧入弦差仍是「接触面相位的合法 tick 语义」而非缺陷）。

**Q3（substep 政策授权，U3）**：背景：扫掠直线段精确 → 穿透不因速度发生；真实高速风险是弧入弦差（3500u/s·R64 → 5.9u）；tick 内 substep 会把 64 边形变 N·64 边形（改写金标准语义）。授权团队按 C-2 双序列 diff 自决（接触事件集恒等 → substep 落 B 默认关；不恒等 → 回 r4 附数据）？选项：A 授权自决（推荐）/ B 现在定死默认关 / C 现在批准条件触发。

**Q4（输入语义，U5）**：背景：tick 模式输入只在 64Hz 边界消费（金标准语义延伸）；亚 tick 点按（<15.6ms）会丢失——耦合 predPhys 有亚 tick 输入优势，解耦 phys 是 1ms 粒度。OR-latch 能补但改输入语义=改金标准。选项：A 忠实快照（推荐）/ B OR-latch 并窗 / C 先看模拟台测的点按时长分布 vs 丢失率再定。

**Q5（tickRate 语义，U6）**：背景：耦合权威线现状是 tickRate+3=67Hz（`worker/main.ts:53` 历史手感裁定）；tick 模式若沿用 +3，金标准机器跑的是 67 边形，与你的 64 边形洞见字面矛盾。选项：A raw 64（三方推荐）/ B 沿用 +3=67。

**Q6（验收硬门禁，U8）**：背景：Gate 2/3 的 exit criteria 拟定为 T1–T6 异常计数=0、P0 逐帧等式、replay-self 逐位重放——作为**阻断性**门禁（不达标不放行）还是建议性指标？选项：A 阻断（推荐）/ B 建议。
