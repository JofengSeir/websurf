# t6 立场备忘·r3.1 渲染先行方案设计（plan-reviewer·框架方）

- 任务：t6（r3.1）。主持四家族对比 → 推荐方案（可组合）+ r3.5 问题（≤3）。
- r3 裁定基线（约束本设计空间）：Q1 否决 36–43ms（原话「不接受这么高的延迟，但渲染是务必走在 tick 之前的」）⇒ **渲染先行成为硬要求，前提②须重新划界**；Q2 三模共存；Q3 授权 C-2 自决 substep；Q4 忠实快照（无 OR-latch）；Q5 raw 64；Q6 阻断性门禁。
- 红线（captain 定）：worker 权威单实例 raw 64t 不动；禁止速度注入式校正与锚定拉回；只服务 tick 模式。
- 收编基座：mode-designer v1.5 协议槽 I_A_SEG（i32[5] 段序号，自愈断窗）/ I_A_TICK（i32[6]）/ I_A_EVT（i32[7] 事件位掩码，take_event 全库零调用 → 帧流=唯一事件真源）+ P-tick-1..8；t4 验收框架 T1–T6；t1 机理分界（A/B/C 三类）。
- **核心定性（先亮刀）**：渲染先行 = 显示时间越过权威网格 ⇒ 必然构造未来值。r2「零渲染推定」在字面上不可与之共存——本设计的任务不是假装合规，而是把推定做成**有界、可撤、可测、语义最小**的三档，并把划界权交用户（r3.5-Q1）。三档推定分级：**公式外推（最弱：不含 accel/clip/重力二阶）< 封帽外推（同上+永不越界）< 真物理截断窗投机（最强：同一 tick 函数、只差输入窗完整度）**。

## 1. 四家族对比（延迟下界 / 忠实性风险 / 边缘伪影风险 / 实现成本）

延迟口径统一（r3.1 语境，144Hz 合成 ≈7ms）：ε_publish ≈ 0–8ms；T=15.6ms；输入对齐均值 0.5T。

| 维度 | F1 有界外推≤1tick | F2 客户端预测+回退重演 | F3 直出+短视界混合 | F4 锚点前移（worker 乐观+修订） |
|---|---|---|---|---|
| **机制** | 消费端从最后已算帧线性外推 P=v_k·Δt，horizon 硬封帽 +1 tick，越帽 hold 至真值 | 主线程第二 PhysWorld 同函数同网格超前一步（部分输入投机），真值到达 → 重播种+重演对账 | 基座=直出真态（阶梯、零推定兜底）；外推只填 (t_k, now] 缝隙、永不越下一边界 | **worker 单实例内**：t_k+δ（δ≈8ms）快照→用部分窗投机算 tick k+1 → 发 rev=0 乐观帧；t_{k+1} 全窗真算 → 发 rev=1 修订帧（=权威终序列） |
| **延迟下界** | 输入→像素 ≈ 10–25ms（均值 ~17；输入效应要到下一真值才可见） | ≈ 15ms 均值 | 同 F1（F1=F3 同族，差异=封帽约定与兜底姿态，见 §2 收敛发现） | **≈ 10–23ms（均值 ~15–17）**：早窗输入（δ=8ms 内，占比 δ/T≈51%）走 ~10–18ms 快径 |
| **忠实性风险** | 推定分级最弱档：线性外推不含 accel/clip/重力二阶（重力二阶 ½gT²≈0.097u 可忽略；air-accel 弦差 ≤1.14u；**方向变化即错**） | 真物理+截断窗（同 F4）；但**主线程第二实例 = ⑤病灶形态复活**（虽无校准写入、权威不可触碰，形态学上回到耦合嫌疑） | 同 F1 | 推定分级最强档：**同一 tick 函数、真物理曲率/clip/重力俱全，只差输入窗完整度**；权威序列零改动 |
| **边缘伪影风险** | 边界 snap = 全输入效应+模型误差：max 甩镜 26.4°/tick 时 ≈ |v|T(1−cos26°) ≈ **5.7u 跳变@3500**；压坡穿透显示 ≤|v_n|T≈0.6u 后 snap | 事件投机危险最大：**teleport/death 投机→显示传送再弹回**（最差档）；压边投机碰撞分歧→snap | 同 F1 但封帽更规整（永不越界、hold 点确定） | 修订 snap = **部分-vs-全窗效应（严格小于 F1 的全效应+模型误差）**；**事件封帽规则：乐观步 take_event 非空（teleport/death 候选）→ 禁发乐观帧、自动退化直出**——投机在最危险处自动关闭 |
| **实现成本** | 极低：纯 TS ~50 行，零协议零 Rust（v_k 已在帧内） | 最高：主线程实例生命周期+输入日志/重演+事件投机策略+主线程确定性面 | 低：F1 变体+直出兜底 | 中：Rust 全量状态快照/恢复（**9 字段 set_state 不够**——contact_ticks/ground_ticks/blocked 计数/duck_frac/trigger 态须逐位往返；新 API + 位级恒等断言）+ 修订槽位 + 消费端缝合层（复用 F3 层） |

## 2. 收敛发现（对比中浮现的结构性结论）

1. **F1 与 F3 是同一机制的两个姿态**：F3=「 conjecture 默认关、缝隙即开、永不越界」；F1=「默认先行、封帽+1」。当 now<t_{k+1} 两者逐位相同；差异只在迟到发布时的 hold 点与默认开关。**收敛为同族双档，不是两个方案**。
2. **F4 在同延迟下严格劣化 F1 的伪影**（修订 divergence=部分输入效应 < F1 的全效应+模型误差），且显示位置是真物理——**代价集中在 Rust 快照面**。
3. **F2 的「回退重演对账」机制本身值得保留——但搬进 F4**：F4 的修订流就是「真值到达→对账」的 worker 内版本，且天然免掉主线程确定性面。F2 整族（主线程实例）不推荐：⑤形态复活 + 事件投机最危险 + 成本最高；其遗产=对账口径（修订 divergence 遥测）。
4. **事件封帽是三家族共同的伪影闸门**：投机在 teleport/death/respawn 候选 tick 自动退化为直出——I_A_EVT 位掩码恰好是现成载体（v1.5 槽位复用，零新增面）。
5. **F4 对插值模式还有溢出收益**：修订帧提前给出下一格真值近似，插值消费器可用修订帧做「预对齐」（可选增强，r3.5 不展开）。

## 3. 推荐方案（可组合）

**主干 = F4（锚点前移：worker 乐观评估+修订流，事件封帽）+ 缝合层 = F3（消费端 ≤ 边界短视界外推，conjecture 默认关）**；**F1 作为无 Rust 快速档保留**（TS-only，~50 行，用于快速可玩验证与 Gate 3.1 伪影对照——量化「公式外推 vs 真物理投机」的伪影差，这本身就是 r3.5-Q1 的证据供给）；**F2 不推荐**（理由 §2.3），但其重演对账口径收编进 F4 验收。

**显示循环（F4+F3 组合的精确语义）**：
- 最新帧 = 修订帧（rev=1，网格点 t_k）：显示时间 ≤ now 的部分线性外推至下一边界封帽（F3 层）；越帽 hold。
- 最新帧 = 乐观帧（rev=0，网格点 t_{k+1}）：**直出至 t_{k+1}、越点 hold**（乐观帧的网格点已是未来，不得再外推=两格领先）；修订到达 → snap ≤ divergence 收敛。
- 事件封帽：乐观步 take_event 非空 → 不发乐观帧，该窗直出真态（I_A_EVT 路由 UI/计时/存点不受影响）。
- 兜底（red-line 继承）：发布迟到/starvation → 冻结最后已发布值 + 计数（**禁止为遮盖而外推**——兜底仍然零外推；外推只属于「正常领先循环」）。

## 4. r3.1 断言层（扩展 P-tick-1..8，编号 P-ra-1..5）

1. **P-ra-1 封帽**：显示时间永不越过「最新已发布帧网格点 +1 tick」；乐观帧直出至自身网格点、不得再外推。
2. **P-ra-2 修订即撤**：修订帧到达后 ≤1 渲染帧内，显示值收敛到修订值（凸组合/直出），乐观值不得残留。
3. **P-ra-3 事件封帽**：take_event 非空 tick 禁止乐观发布（遥测逐次计数）。
4. **P-ra-4 快照位恒等**：快照→恢复→tick ≡ 直跑（逐位，0 容差；覆盖 contact_ticks/ground_ticks/blocked/duck_frac/trigger 态全内省面）——F4 的准入门禁。
5. **P-ra-5 修订 divergence 遥测**：|opt−rev| 逐 tick 分布入遥测，S3 边缘场景（薄沿/弯坡/出坡）专项出分布；E[div] 与 P99 是 r3.5-Q3 观感裁决的数据供给。
- 继承：P-tick-7（稳态无反写）对 F4 天然成立（乐观评估不反写）；P-tick-1（序列恒等）对**修订后的权威序列**成立（乐观帧不入权威序列）。

## 7. 收敛修订 v2（mode-designer 立场收编 + L 对消定理）

### 7.1 L 对消定理（输入→光子口径，标签前移贡献恒为零）

mode-designer 的 D 家族（锚点前移=累积器提前 L 开火、前沿标签领先）其延迟表须修正：设状态 k 标签 t_k、开火 c_k=t_k−L（输入窗 (t_{k−1}−L, t_k−L]，窗长恒 T、**无缝铺贴**）、发布 p_k=c_k+ε。平滑显示下光子时刻 = τ 达标签：wall = t_b + Δ，Δ=T+ε_max−L ⇒ **wall = c_b + T + ε_max——L 精确对消**。输入→光子 = 对齐(均值 T/2) + T + ε_max + 合成 ≈ **31.4ms（Atomics）/ 38.8ms（setTimeout），与 L 无关、与 Gate-1 插值相同**。其表内「单 D ~24–27 / D+C ~15–20ms」为发布→光子（新鲜度）口径，交付 r3 时必须换算。D 的真实收益 = hiccup 韧性（P-tick-9）+ Q1 的标签读法；但**内容仍整 tick 旧**——「算得更早不必猜未来」对 D 不成立（D 是标签早、内容不早；**F4 才是内容早**：乐观评估=提前 δ 的额外计算）。

### 7.2 DIA 曲线与三难困境（r3.5-Q1 的重构基础）

**DIA（显示内容输入龄）** = now − 显示状态最新输入截止，玩家体感 = 对齐(T/2) + DIA + 合成：

| 方案 | DIA | 输入→光子（均值，Atomics） | 推定性质 | 最坏误差 |
|---|---|---|---|---|
| D 纯 + 标准插值（任意 L） | T+ε_max ≈ 16.6 | **31.4ms** | 零推定 | 0（平移相位不改内容） |
| A/C 公式外推，H 旋钮 | T−H | H=8ms→**23.4ms**；H=T→**15.8ms** | 有界公式推定（须 Q1 追认） | 弯折 O(\|v\|·H)：28u / 55u≈半弦 |
| F4 乐观评估+修订（δ=8ms） | T−δ ≈ 7.6 | **≈22.4ms**（8–23 区间） | 真物理截断窗（须 Q1 追认） | 修订 divergence=后 δ 窗输入效应（小，P-ra-5 计量） |
| B 投机输入 | ≈0–5 | **<15ms** | 未出生输入猜测 | ⑤形态复活+猜测误差 |

**三难困境**：平滑（需 T 缓冲或视界桥）/ 低延迟（<25ms 需 DIA<10ms）/ 零推定——不可兼得。D 纯+插值=平滑+零推定但 31.4ms；D 直出+小 H=快但 54.7u 阶梯残留（违反流畅度硬要求）；平滑+快必须付出推定。

**口径与前置条件注记（bench v2.4 §9 对拍增补）**：
- **延迟数字均为解析期望值**，感知口径敏感（首见-部分可见 vs 全权重可见差 ≈T−δ）——**交付口径以 bench §5.1(b) D-scan 按家族发布器剖面出具为准**，解析值降级为对拍假说。F4 结构分解：快径等待 = (t_k+δ−w0)+ε_publish（**无 tick 对齐项**——8ms 跨度变量=输入在乐观窗内相位 w0−t_k∈(0,δ]，非 rAF 相位；ε_publish 叠加 0–8；合成 ≈7 常数）；慢径等待 = (t_{k+1}−w0)+ε_publish。**对拍假说：两路径均值收敛 ≈15ms（δ/T≈51% 权重下）**——D-scan 可证伪。
- **前置条件硬约束（命运劈分）**：**A/C/D 免全态导出**（零 Rust 即落地）；**F4/B 强依赖 wasm 全态导出**——P-ra-4 分两层：rig 层裸内存快照（L-a 已覆盖，非新验证）/ **产品层 set_state 才是真门**（9 字段缺 stuck 6-tick 计时器 PL:875-892/teleport 冷却 armed/接触态/跳跃边沿——恢复即分歧）；**缺字段发现协议**：set_state 恢复→tick vs 裸快照恢复→tick 位级 diff 驱动字段猎取。预期结论=wasm 需全态导出（P3-A1 家族）。**章程注记（bench §8.14，终态=轨 B 定案）**：本团队禁实现代码/禁模拟台——captain 曾批一次性豁免（轨 A）后**收回，改判轨 B 定案：团队内不执行**；发现协议移交下一团队首件（可执行规格 v1 已备：四状态类 s1 着地/s2 surfing/s3 跳跃+落地/s4 teleport × 裸快照 vs set_state 往返位级 diff，schema 含 repro_hypothesis）；**r3.5-Q2′ 证据结构=静态嫌疑清单基线（stuck 6-tick PL:875-892/teleport 冷却 armed/接触态/跳跃边沿 + 研究员快照面清单）+ 前置条件二分 + 显式可选项「授权发现协议实测（<1h）」交用户**；t6 终版推荐不被阻塞（前置条件二分两种结局下均成立），仅 F4 成本置信级随用户是否授权实测而变。
- **P-ra-6（bench 提案，采纳）**：①事件无损（乐观+回放事件序列≡权威事件序列）；②无重复消费（恢复后重放不重触发 take_event——即研究员 peek 语义问题的台侧测试对）；③禁发帧空档 ≤1 tick。I_A_EVT 载体复用。

### 7.3 统一谱系推荐（替换 §3）

- **主干 = F4（真物理截断窗 + 修订流 + 事件封帽）**：唯一「内容早」的合规形态；需 Rust 全态快照（P-ra-4 门禁）——与 B 共用同一快照面。
- **降档谱系 = A/C（公式外推 H 旋钮，零 Rust）**：H=8ms 档（23.4ms/28u）为默认候选；H=T 档（15.8ms/55u）须用户明确接受。
- **可用性层 = D 整族收编**：P-tick-9（lead 恒定 ≥L−ε + hiccup 后 5s 回填 ≥90%）、相位自由度结论（Q4 语义不破——输入窗无缝铺贴=相位选择非语义变更）、相位披露签收。
- **B 门控保留**：仅当用户要求 <20ms 且明示接受双计算受控形态；mode-designer a/b/c 三门禁 + 参数哈希恒等对冲（检测非消除，立场一致）收档。
- mode-designer D 行延迟口径更正 + B 家族断言存亡表（P-tick-2 渲染路失效/P-tick-7 改写 rollback 白名单/参数路径 1→2 §4.5 失效）原样收档为其 v1.7 贡献。

## 9. 研究员立场收编（判分输入，备忘 §10）

### 9.3 显示策略洞（我方收敛关键发现——研究员延迟账的缺失半边）
**研究员均值 ~11ms = 直出 freshest tick 口径**（其账中无插值缓冲项）——直出=64Hz 阶梯（3500u/s=54.7u/15.6ms 跳变），违反流畅度硬要求。平滑显示需 τ 领先弦插值 ⇒ **必须叠加 mode-designer 的 L 相位机制**：canonical 网格前移 L（影子 owns 累加器故天然设定相位；权威随台账边界同相位跑），τ-leads-wall 插值（两真实态间弦插值，零推定）→ **延迟 = 对齐(T/2)+ε+comp ≈ 15.8ms 均值 / 23.6ms worst（Atomics），DIA ≈ ε**。无 L 时平滑回退=τ 拖尾 31.4ms（Q1 否决域）。**结论：研究员家族-1 与 mode-designer L 机制是同一方案的互补两半**——合成态记为 **L-combo（双跑 lockstep + L 相位 + τ 领先插值）**。

### 11.2 事件泄漏路径实证 + F4-C 升格主案（第四解）
- **无槽还原=结构性事件泄漏**：封帽只挡乐观帧发布、不撤销乐观步的槽写入——乐观步触发 teleport→槽=E_opt；真步几何分叉未触发→权威下次 take_event 吐出「从未发生的步」的幽灵事件。mode-designer 恢复带回方案在还原变体内由「可选」升格「必需」。
- **第四解=F4-C（scratch），研究员推荐主案**：乐观评估在 worker 内第二实例跑，**权威实例从未被触碰**；快照机器降格**纯播种**（seed-only：无还原路径、无还原正确性风险面）；scratch take_event 随意排空（事件随实例丢弃，权威真步确定性重放同一事件，逐位同）——**peek 两难结构性消解、事件槽需求整体消失**。代价=worker 内第二 wasm 实例（世界碰撞数据一次性复制几 MB+每评估廉价字段重播种）+同字段表作播种面。
- **F2（主线程影子=L-combo 架构）最终不推荐——两层分开记**：因果层面零写 lockstep 等价成立（**非 B 类失真**）；不推荐理由=工程性：①调度域分裂（主线程 jank 杀镜像视界；F4-C 乐观+修订同在 worker 单一调度域）②事件显示面（主线程渲染预测事件=teleport 显示弹回最差档；F4-C 封帽把事件面留在 worker）③成本最高。**措辞纪律：「形式风险+工程劣化」，不写「B 类失真」**（§7.2 B 行同步修正）。

### 11.3 divergence 双桶断言 + 封帽谓词扩展（P-ra-5/P-ra-3 修订）
- **F4 divergence 主项=延迟输入窗（T−δ 段）的单 tick 输入相位效应**——sim 函数同一，分歧**非混合态伪影**，是「输入后缀晚一 tick」的另一条合法轨迹（与耦合线校准失真机理分离——定性关键）。
- 四项分解（P-ra-5 S3 对照）：**T1** 延迟 yaw/位移（Δyaw≤maxStep·(T−δ)/T·M_YAW≈12.8°→弦位差 ≤1.36u@3500+增益错位 ≤0.5u→bulk ≤~2u）；**T2** clip 判定翻转（F2′ 分支 A/B 移植；翻转窗≈bulk div/|v_n|；div≤一 tick 法向响应 |v·n|）；**T3** 落地/step 链翻转（乐观已落地钳 275+摩擦+投影 vs 修订仍空中→~26u@2000+land_punch 相机效应——有界但大、罕见）；**T4** trigger 穿越翻转（封帽拦住→显示 div=0；代价=真步事件晚 ≤1 tick=A 类相位）。
- **div_cap 拆双桶**：div_bulk ≤2-3u（非翻转 tick，硬断言）+ **div_flip**（翻转 tick 独立计数+分支界 5-30u；S3 出翻转率分布；超阈值→收紧封帽→乐观发布率下降/早窗占比 49% 收缩——诚实预算）。
- **封帽谓词扩展（漏网面实证）**：「take_event 非空」只拦 T4；**T2/T3 接触判定翻转不是事件**→最坏 26u 显示弹跳漏过。扩为**状态不连续检测**：take_event 非空 ∨ on_ground 翻转 ∨ blocked_ticks/stuck_ticks 增量 ∨ on_ladder 翻转 ∨ ducked 翻转（乐观步后廉价字段读，零新 trace 面）。S3 专项验证翻转率：低→谓词实用；高→预算权衡实测（发布率塌向 F3）。
