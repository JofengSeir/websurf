# tick 模式用户手测指引（t5 草案·供 t8 真机 A/B 包收编 · consumer-engineer · 2026-09-10）

> 团队纪律：禁真实浏览器——本文档是给**用户手测**的操作与观测指引；团队只备遥测面板与数据面。
> 本稿随 t5 实现演进更新；字段名以最终接线为准。

## 1. 三模式切换

面板下拉 `computeMode`：`coupled`（耦合逐帧物理，现行基线）/ `decoupled`（解耦自驱）/ `tick`（tick 权威 + F4-C scratch 乐观评估——本任务新增）。

- 切换发起：下拉选择 → 主线程 set-mode 握手（500ms 超时重发一次 → 仍无 ack 回滚到发起前模式，面板与 config 同步回滚）。
- **coupled → tick 必带交接快照**（位置/朝向/速度/着地 9 字段注入 worker 权威实例——切换瞬间无传送感）；decoupled → tick 零注入（worker 实例本来就是真理源）。
- 进入 tick 后：worker 独占物理（raw 64Hz，无 +3 偏移），主线程零物理实例——只做插值显示消费。
- 切出（tick → coupled/decoupled）：worker 停 tick 发布；耦合预测线懒建/解耦自驱接管。

## 2. tick 模式的期待手感

- **正常运动**：平滑匀速——α 网格弦插值（显示时间落后真值 ~24ms 预算内，肉眼看为轻微但连续的延迟感，无步进/抖动）。
- **早窗提前显示**（F4-C 乐观评估）：输入后 ~7.6ms 内画面先动（scratch 乐观帧直出），真值 ~15.6ms 后到达并"修订"显示（差异 ≤2-3u 量级，理论无感）。key 事件 tick（跳跃等键边沿）会跳过乐观发布（key-edge gating）——该 tick 无提前，属设计内。
- **断窗场景**（teleport/respawn/存点读取/world 重建/模式交接）：瞬间直出新段帧，**禁止跨界插值**（不会出现扫场拖影）；seg 号 +1 自愈。
- **显示永不倒退**：显示时间单调钳制（硬不变量①）——若你观察到画面回跳，记下场景与秒数，这是 Gate 2 异常信号。

## 4. D10 三类异常观测点（定向验证，两模式对照）

在 **coupled 与 tick 两个模式**下分别体验并回答：异常出现在哪个模式（耦合默认 / tick / 两者）？
1. **不可预测减速**：贴墙/斜坡加速中突然变慢；
2. **幻影碰撞**：视觉未接触障碍却被阻挡/弹回（≤60u snap 形态）；
3. **意外运动**：未输入方向却位移/转向（校正器族形态）。

（解读钥匙仅团队用：#4 set_velocity 扼流=减速 / #3 ≤60u snap=幻影碰撞 / #7 校正器族=意外运动。）

## 5. 已知边界（设计内，非 bug）

- 蹲姿（ducked）不随热切交接（Rust 零改动定稿 §3.9-P7①）——切模式后蹲起自愈；
- key 事件 tick 无乐观提前（key-edge gating，div=0 代价）；
- starved/回滚场景显示短暂冻结（零外推红线——宁可不墙不外推）；
- 显示延迟预算 ~24ms（Δ=T+8ms guard）：与耦合模式直感差异在此量级。
