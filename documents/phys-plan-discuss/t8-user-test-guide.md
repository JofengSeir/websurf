**A/B 纪律（重要）**
1. 同一台机器、同一浏览器、同一地图与出生点、同一画面设置（FOV / 画质）；
2. **先 A 臂（coupled）后 B 臂（tick）**，每臂开始前**刷新页面一次**（避免跨臂测量污染）；
3. 每臂结束后**立刻复制遥测文本**（§5），再切下一臂；
4. 每类异常发生时，除主观描述外**必须留下遥测原文**（面板 500ms 轮询会冲掉异常窗口——用「冻结」秒停后复制，见 §5）。

## 2. 模式切换与交接确认（Step 1）

1. `ESC` 打开控制面板 → **通用** → **物理计算模式 / 计算模式**下拉：`coupled（预测 + 权威校准）` / `decoupled（Worker 权威）` / `tick（权威 64Hz + 乐观评估）`。
2. 切到 `tick` 后，面板中 **「tick 消费遥测（实测列）」** 区域自动出现；切出后自动隐藏。
3. 交接手感：`coupled → tick` 为**带快照交接**（位置/朝向/速度/着地等注入 worker 权威实例），切换瞬间**不应有传送感**；`tick → coupled/decoupled` 时 worker 停止 tick 发布。
4. **已知边界（设计内，不是 bug）**：
   - 蹲姿（ducked）不随热切交接——切模式后蹲起自愈；
   - key 事件 tick（跳跃等键边沿）**不发布乐观帧**（key-edge gating）——该 tick 无提前量，属设计；
   - 饥饿/回滚场景显示会短暂冻结（**零外推红线**：宁可冻结不外推）。

## 3. A 臂：coupled（现行基线，Step 2）

按顺序做这 5 段，每段记录「是否出现异常 + 大致秒数 + 复现次数」：

1. **平跑加速**：直道加速到高速，观察是否平滑匀速；
2. **贴墙 / 斜坡加速**（surf 边缘）→ 观察 **①不可预测减速**（加速中突然变慢）；
3. **薄沿 / 凸棱落地** → 观察 **②幻影碰撞**（视觉未接触却被阻挡/弹回）；
4. **转向与急停起步** → 观察 **③意外运动**（未输入方向却位移/转向）；
5. **传送 / 存点读回**（`X` 存点、`C` 读最近存点、地图传送触发）→ 观察有无扫场拖影。

> A 臂是**对照组**：出现异常是预期事实（校正器族基线行为），要的是**量化与场景**，不是「没有异常」。

## 4. B 臂：tick（本任务新增模式，Step 3）

重复 §3 的五段动作（同图同路线），另外观察 tick 专属项：

| 观测项 | 期待 | 异常信号 |
|---|---|---|
| 平滑度 | 连续、无步进/抖动（存在轻微但连续的延迟感） | 明显跳变、抖动、画面回跳 |
| 早窗（乐观评估） | 输入后画面**先动**，真值到达后「修订」，差异 = div bulk 桶量级（t7 实测：bulk p99 ≤2.5u 计划内；**flip 桶 P99=4.627u、最大 4.627u**——集中在 bhop 落地/接触翻转相位） | 修订可见、闪回、双击感 |
| 断窗场景 | 传送/重生/存点读/world 重建/模式交接 → **瞬间直出新段帧**，禁止跨界插值 | 扫场拖影、跨界拉丝 |
| 显示永不倒退 | 显示时间单调（硬不变量①） | 画面回跳（**Gate 2 异常信号**，务必记录秒数） |
| 显示延迟 | t7 D-scan：**knee（出现 hold 的最小 Δ）= 144Hz 档 11.75–13.5ms / 240Hz 档 13.25–17ms**（剖面 none/atomic1/jitter8/gctail；gctail@144 扫描范围内无 knee，minHold=0.0147）。注意 knee 是「配置 Δ」而不是分位估计 | 与耦合臂直感差异明显超出该量级 |

## 5. 遥测面板解读（Step 4）

进入 tick 模式后面板出现 5 行（**逐字对照**，字段名以下表为准）：

| 行 | 面板字面（前缀） | 含义 | 健康值 |
|---|---|---|---|
| 1 | `显示态: …` | 六显示态占比：弦插值 / 截断窗外推 / 乐观直出 / 节拍保持 / 饥饿冻结 / 断窗直出 | lerp 为主；hold-*/断窗 偶发 |
| 2 | `fallback: … starved: … Δ_eff: …` | 兜底率 / 发布迟到累计 / 当前生效插值延迟 | fallback <5%；starved <1 次/10s；Δ_eff ≈ 23.625ms（T=15.625 + guard 8） |
| 3 | `div 双桶: bulk 最大 … 硬违例 … flip p99 …` | 直跳双桶：≤2.5u 计划内 / flip 独立计数 + P99 逃逸 | bulk 硬违例 **0**；P99 逃逸**不亮** |
| 4 | `policy: … OPT: … lead … pubLag …` | F4 政策 / 乐观帧计数 / 提前量 / 发布滞后 | 稳态 `f4`；leadMiss 低频 |
| 5 | `P0 自检: α 违例 … / 凸组合违例 …` | 逐帧等式自检计数（设计恒 0） | **必须为 0**（非 0 = Gate 2 阻断信号） |
| 6 | `worker 账: f4Ready … ｜ 门 发 …/miss …/blocked … ｜ worker div: bulk …(max …u) flip …(max …u) 超帽 … ｜ 跳过: 地板 …/孤儿封帽 …/key 边沿 …/引导 … ｜ 修订 … \| hold … \| 段 …/标号 …` | **worker 侧**账（`TickF4Stats`）：门三计数 / worker div 双桶 / 地板跳过 / 孤儿封帽 / key 边沿 / 引导跳过 / 修订数 / 段与标号 | `f4Ready ✓`；`地板/孤儿封帽/key 边沿` 低频；`超帽` 应恒 0；未收到消息时显式打「（未收到 tick-stats）」**而非 0** |
| 7 | `取证: 打点 N/20 \| 会话 <标签>` | 打点缓冲占用与会话标签 | 会话标签非空（A/B 两臂可区分） |

**取证操作（已落地，t8）**：面板 tick 遥测区内提供 ——
1. **会话标签**输入框（默认 `-|tick <时间戳>`；建议每臂开始时改成 `A|coupled …` / `B|tick …`，写入 localStorage 记忆）；
2. **冻结遥测**（暂停 500ms 轮询刷新、保留最后快照）/ **复制遥测**（一键复制 7 行全文，含会话标签首行；clipboard 失败时自动回退 execCommand）；
3. **异常打点**（点按瞬间直读遥测入本地缓冲，**绕开 500ms 冲窗**，上限 20 条 FIFO）/ **复制打点**（导出全部打点：序号 + ISO 时间戳 + 会话 + state/policy + 快照全文）。
异常发生时先「冻结遥测」→「复制遥测」→（必要时）「异常打点」，再继续操作。

> **回报硬要求**：任何异常回报都必须附**第 5 行原文**（`P0 自检`）——它是唯一「用户可见的 Gate 2 阻断信号」。

## 12. 已知预期现象清单（**64 边形语义 = 忠实表现，不是 bug**）

| 现象 | 为什么是「忠实表现」 | 与「异常事件判据」的区分 |
|---|---|---|
| 高速贴坡时可见极轻微折线感/微跳 | 权威物理是 **64Hz + 几何离散化（64 边形口径）**；面由有限平面近似，高速掠过时离散化误差可见 | **不算异常**：无事件、无位移越界、div 在带内即为忠实语义 |
| 显示的「轻微延迟感」 | 显示层是**弦插值回放**（零外推红线）：显示时间落后真值一个 Δ 预算 | **不算异常**：Δ_eff 稳定（≈23.6ms 工作点）即正常 |
| 键边沿 tick 无提前量 | key-edge gating：该 tick 跳过乐观发布 | **不算异常**：`key 边沿` 计数增长属设计 |
| 切模式后蹲姿不延续 | 蹲姿不随热切交接（Rust 零改动定稿） | **不算异常**：蹲起后自愈 |
| 饥饿/回滚时短暂画面冻结 | 零外推红线的兜底（宁可不墙不外推） | **不算异常**：`starved`/`hold-*` 低频 |
| 死亡/传送瞬间「跳」 | 断窗直出（禁止跨界插值） | **不算异常**：`段` 号自增即正常 |

**真正的异常事件判据**（任一命中即回报，附遥测原文）：①`P0 自检 α 违例 / 凸组合违例` **非 0**；②`div 双桶 bulk 硬违例` **>0**；③**显示回跳**（画面倒退）；④未输入却位移/转向；⑤视觉未接触却被阻挡/弹回（幻影碰撞）；⑥传送/死亡出现拖影或插值飞行；⑦`fallback ≥5%`、`starved ≥1 次/10s`、`Δ调节 ≥20 次/5s`。

## 13. D10 定向验证点：**tick 模式下的「应消失项」清单**

用户裁定：D10 定向复现 = 两类异常对照；台架侧已用复刻线固定基线（t7：COUPLED×T2 减速**已复现**、COUPLED×T3 幻影阻挡**已复现**、COUPLED×T4 未复现）。真机侧请在 **B 臂（tick）** 逐条确认下列项**是否消失**：

## 14. 三模共存回归冒烟指引（coupled / decoupled 零回归快速自检）

改造后必须确认另两条模式**零回归**（tick 是新增分支，不得影响既有两模）。按顺序做，约 3 分钟：

1. **切回 coupled**（面板下拉），做上面 §11 的第 2、3 项（压边/出坡）：
   - 手感应与改造前一致；**tick 遥测区必须消失**（若仍显示 → 立即上报）；
   - 若你熟悉改造前的基线，可直接对比观感。
2. **切到 decoupled**：确认能正常运动（该模式=解耦自驱，属**已知「r2 违例基线」**：其失真现象**不修复、不漂白**，出现属预期，不是本次回归项）；
   - 同样要求 **tick 遥测区消失**。
3. **往返热切**：`coupled → tick → coupled → decoupled → tick` 各一次，每次观察：
   - 切换瞬间**无传送感**、无卡顿、无控制台报错；
   - 每次进入 tick 后遥测区重新出现，`P0 自检` 两计数重新计为 0 并保持。
4. **冻结/复制自检**：进入 tick 后点「冻结遥测」→ 数值应停止变化 → 点「复制遥测」→ 剪贴板应得到含会话标签的 7 行文本 → 点「恢复刷新」→ 数值继续变化。
5. 任何一步不符合 → 记为回归，附**两种模式的遥测原文**（tick 侧连 `worker 账` 行一起复制）。
