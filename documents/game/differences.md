# WebSurf-game 与另两个工程的实测差异

本表每条差异都在两侧各自实测并给出锚点；「对比工程」列写明是对 `apps/debug` 还是 `apps/viewer`。无差异的维度显式写出「本维度两工程实现一致」。

| 维度 | 本工程（`apps/game`） | 对比工程 | 证据（两侧锚点） |
|---|---|---|---|
| 渲染后端 | three.js `WebGLRenderer`，`antialias: true` + `powerPreference: 'high-performance'` | `apps/debug` 同为 three.js `WebGLRenderer` | 本维度两工程实现一致：`apps/game/src/renderer/renderer-main.ts:276`、`apps/debug/src/renderer/renderer-main.ts:408` |
| 渲染后端 | 同上 | `apps/viewer` 同为 three.js `WebGLRenderer` | 本维度两工程实现一致：`apps/game/src/renderer/renderer-main.ts:276`、`apps/viewer/src/core/scene.ts:95` |
| 页面布局 | 单画布 `#preview` + 覆盖层（`#hud`、`#keys`、`#fps`、`#loadingOverlay`、`#panel` 常驻覆盖层）；样式外置为 `web/styles.css` | `apps/debug` 为 flex 纵向布局：`#app` 列布局 + `#topbar` 顶栏，样式**内联**在页面 `<style>` 里 | `apps/game/web/index.html:27`、`apps/game/web/index.html:18`；`apps/debug/web/index.html:34`、`apps/debug/web/index.html:35`、`apps/debug/web/index.html:7` |
| 页面布局 | 同上 | `apps/viewer` 画布 id 是 `game`（不是 `preview`），样式外置为 `web/styles.css` | `apps/game/web/index.html:27`；`apps/viewer/web/index.html:12`、`apps/viewer/web/index.html:8` |
| 物理运行位置（权威） | Worker 权威物理由 `createAuthLoop` 装配，主线程侧另有「主线程渲染物理（`predPhys`）」 | `apps/debug` 同为 Worker 权威物理装配 | 本维度两工程实现一致（装配入口同名同形）：`apps/game/src/worker/main.ts:451`、`apps/debug/src/worker/main.ts:455` |
| 物理运行位置（本端） | 主线程持一个 `PhysWorld` 作「主线程渲染物理（`predPhys`）」，每帧 `tick` 推进 | `apps/debug` 同样在主线程建 `PhysWorld` | 本维度两工程实现一致：`apps/game/src/renderer/renderer-main.ts:689`、`apps/debug/src/renderer/renderer-main.ts:1133` |
| 物理运行位置（本端） | 同上 | `apps/viewer` **无任何物理实例**：`apps/viewer/src` 内 `PhysWorld` 零匹配，只有离线解析（`websurf-wasm-core`） | `apps/game/src/renderer/renderer-main.ts:689`；`apps/viewer/src/core/bsp.ts:121` 只构造 `BspProcessor`，且 `apps/viewer/crates/wasm/Cargo.toml` 无 `websurf-phys` 依赖行（该文件 `apps/viewer/crates/wasm/Cargo.toml:5` 写明不含物理） |
| 物理依赖声明 | `websurf-phys = { path = "../../../../src" }` | `apps/debug` 同一声明 | 本维度两工程实现一致：`apps/game/crates/wasm/Cargo.toml:22`、`apps/debug/crates/wasm/Cargo.toml:22` |
| 共享状态通道 | `SharedArrayBuffer` 可用时建 SAB 通道，否则 `null` 落入 postMessage 回退；两端各建一次 | `apps/debug` 同一机制、同一入口函数 | 本维度两工程实现一致：`apps/game/src/app.ts:112`、`apps/game/src/app.ts:158`；`apps/debug/src/app.ts:289`、`apps/debug/src/app.ts:325` |
| 共享状态通道 | 同上 | `apps/viewer` 不用通道：不改写物理、不需要 `SharedArrayBuffer`，只在启动时打印该状态 | `apps/game/src/app.ts:158`；`apps/viewer/src/app.ts:37`，且 `apps/viewer/src` 内 `createMainSharedState` 零匹配 |
| 配置来源 | 七段配置的唯一默认值在 `DEFAULT_CONFIG`，`createConfig` 用 `structuredClone` 复制 | `apps/debug` 同样集中在 `DEFAULT_CONFIG` + `createConfig` | 本维度两工程实现一致（段名不同、机制相同）：`apps/game/src/config.ts:176`、`apps/game/src/config.ts:239`；`apps/debug/src/config.ts:205`、`apps/debug/src/config.ts:299` |
| 配置来源 | 默认 FOV 写在 `config.ts` 的 `hud.fov` | `apps/viewer` 无 config 模块：同名量作为模块常量写在自己的常量单点里 | `apps/game/src/config.ts:209`；`apps/viewer/src/core/constants.ts:38` |
| 构建产物形态（single） | `KEEP_SINGLE` 5 项：`index.html`、`app.js`、`styles.css`、许可证两份 | `apps/debug` 的 `KEEP_SINGLE` 4 项且**不含** `styles.css`（页面样式内联） | `apps/game/scripts/build-dist.mjs:60`；`apps/debug/scripts/build-dist.mjs:63` |
| 构建产物形态（single） | 同上 | `apps/viewer` 的 `KEEP_SINGLE` 8 项，除页面三件外还带 `.nojekyll`、`README.md`、`serve.py`、`play.cmd`、`play.sh`（部署站形态） | `apps/game/scripts/build-dist.mjs:60`；`apps/viewer/scripts/build-dist.mjs:51` |
| 构建产物形态（multi） | `KEEP_MULTI` 相对 single 多出 `worker.js`、外置 wasm、`textures.mtz`、`coi-serviceworker.js`；形态开关是命令行 `--multi` | `apps/debug` 同样两形态、同样开关 | 本维度两工程实现一致：`apps/game/scripts/build-dist.mjs:62`、`apps/game/scripts/build-dist.mjs:74`；`apps/debug/scripts/build-dist.mjs:64` |
| 面板与 UI 结构 | ESC 面板 `#panel` 分八栏：`general` / `physics` / `hull` / `keys` / `look` / `display` / `view` / `health`，切换由 `data-mod` → `data-pane` 的事件委托完成 | `apps/debug` 页面无 `data-mod` / `data-pane`（实测零匹配），其参数区在 `#topbar` 之下的自有布局里 | `apps/game/web/index.html:77`、`apps/game/web/index.html:78`、`apps/game/src/panel/panel-controller.ts:106`；`apps/debug/web/index.html:35` |
| 面板与 UI 结构 | 同上 | `apps/viewer` 的界面由 TypeScript 类构建（地图信息面板、回放面板、轨道面板），页面只提供挂载点 | `apps/game/src/panel/panel-controller.ts:37`；`apps/viewer/src/ui/mapinfo.ts:44`、`apps/viewer/src/replay/panel.ts:43`、`apps/viewer/src/replay/trackpanel.ts:37` |
| dev 端口与入口 | `npm run dev` 起 `src/serve.py` 于 8090，服务根为工程目录 | `apps/debug` 是 8080；`apps/viewer` 是 8100 | `apps/game/package.json:15`；`apps/debug/package.json:15`、`apps/viewer/package.json:18` |
| 测试与门禁脚本 | 四个：`check:api` 契约检查 + 三个 node 直跑物理冒烟（`test:phys` / `test:seed-smoke` / `test:surf-crouch`） | `apps/debug` 的脚本更多，且多数先经 esbuild 打包再跑（`test:jump-apex`、`test:auth-clock`、`test:optimize-scene`、`test:path-acceptance` 等） | `apps/game/package.json:16`、`apps/game/package.json:17`、`apps/game/package.json:18`、`apps/game/package.json:19`；`apps/debug/package.json:19`、`apps/debug/package.json:23`、`apps/debug/package.json:24` |
| 测试与门禁脚本 | 契约检查脚本的清单是**本工程自己**的 `EXPORT_API` / `PHYS_API` 两张表 | `apps/viewer` 只跑 `check:api` 与回放自测 / 冒烟（`test:replay`、`local:smoke`），无物理冒烟脚本 | `apps/game/scripts/check-wasm-api.mjs:55`；`apps/viewer/package.json:10`、`apps/viewer/package.json:11`、`apps/viewer/package.json:17` |
