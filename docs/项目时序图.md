sequenceDiagram
    participant Hardware as 硬件层 (1ms 输入)
    participant Kernel as 浏览器内核 (蓄水池)
    participant Main as 主线程 (渲染 + 输入采集 + 预测物理模拟)
    participant SharedMem as 共享内存 (SAB)
    participant WorkerA as Worker-A (权威物理 / 固定步长)
    participant GPU as 图形硬件

    Note over SharedMem: *** 布局与内存序约束 ***<br/>Int32 控制区: V_A (release/acquire) + gen_A + keys + onGround<br/>BigInt64 输入槽: dxAcc/dyAcc 原子累加 (防溢出)<br/>权威全状态双缓冲 S_A[0] & S_A[1] (release/acquire)<br/><br/>*** 同步内容 (2026-08-07 v4.1) ***<br/>权威全状态: pos + yaw/pitch + vel + eyeHeight + onGround<br/>用途: 主线程预测实例 set_state 修正基线 (客户端预测纠偏)

    Note over Hardware, GPU: === 第一阶段：输入捕获 ===
    loop 每 1ms 硬件信号
        Hardware->>Kernel: 推送原始增量位移
        Kernel->>Kernel: 内核级队列缓存
    end

    Note over Hardware, GPU: === 第二阶段：帧起始 —— 输入提取 (无上限) ===
    Main->>Main: 记录 lastFrameTime, now = performance.now()
    Main->>Kernel: 提取自 lastFrameTime 以来的**所有**未取输入 (无上限)
    Kernel-->>Main: 全部原始信号
    Main->>Main: 清洗、合并、削平 (CLAMP, 不丢弃)
    par 权威通道
        Main->>SharedMem: Atomics.add(输入槽, 总增量) + store keys *** BigInt64 饱和保护, 绝不丢 ***
    and 预测通道
        Main->>Main: 同一份输入喂给预测实例输入缓冲 (主线程 wasm PhysWorld)
    end

    Note over Hardware, GPU: === 第三阶段：渲染帧 —— 客户端预测 (rAF, 无上限) ===
    Main->>SharedMem: acquire 读取 V_A
    alt V_A 已刷新 (权威新帧)
        Main->>SharedMem: 根据 (V_A-1)&1 选择双缓冲槽
        Main->>SharedMem: acquire 读取权威全状态 (无撕裂)
        Main->>Main: set_state 修正预测实例 (位置/角度/速度/着地覆盖)
    end
    Main->>Main: 预测实例 predict(dt, keys, dx, dy) —— **真实物理模拟**<br/>(移动语义 + 碰撞; 与权威同源 wasm 模块)
    Main->>Main: 渲染预测状态 (相机 = pos + eyeHeight; 角度 度→弧度)
    Main->>GPU: 提交渲染指令 (基于预测状态)
    GPU->>GPU: 光栅化 & 像素处理
    GPU-->>Main: 渲染完成

    Note over Hardware, GPU: === 第四阶段：权威物理 (固定步长, 不设上限) ===
    loop 自驱循环 (Atomics.wait 16ms 超时兜底; 固定步长累积器无封顶, 不丢物理时间)
        WorkerA->>WorkerA: 累积器推进 (不设步数上限)
        WorkerA->>SharedMem: exchange 消耗输入 (maxStep 防穿墙, 随步长缩放)
        WorkerA->>WorkerA: wasm tick (完整物理: 碰撞/传送/死亡)
        WorkerA->>SharedMem: 写权威全状态到双缓冲槽 (V_A&1)
        WorkerA->>SharedMem: release 递增 V_A + gen_A (内存屏障)
        Note over SharedMem: 状态先于版本号可见
    end

    Note over Hardware, GPU: === 第五阶段：位置突变事件 (respawn / teleport) ===
    Main->>WorkerA: respawn / teleport 消息
    WorkerA-->>Main: player-respawn (pos + yawDeg 回传一次)
    Main->>Main: 预测实例 set_state 归零到权威新位置 + 清预测输入缓冲
    Note over Main: 位置突变时权威覆盖预测, 平时靠每帧权威修正纠偏

    Note over Main: 循环回到第二阶段
