sequenceDiagram
    participant Hardware as 硬件层 (1ms 输入)
    participant Kernel as 浏览器内核 (蓄水池)
    participant Main as 主线程 (零等待渲染驱动)
    participant SharedMem as 共享内存 (缓存行对齐 + 内存屏障)
    participant WorkerA as Worker-A (权威物理 / 64Hz)
    participant WorkerB as Worker-B (预测预计算)
    participant GPU as 图形硬件

    Note over SharedMem: *** 布局与内存序约束 ***<br/>偏移 0-63: V_A (release/acquire) + 权威代际 gen_A<br/>偏移 64-127: 输入槽 (BigInt64 原子累加, 防溢出)<br/>偏移 128-191: 权威状态双缓冲 S_A[0] & S_A[1] (release/acquire)<br/>偏移 192-255: 预测状态双缓冲 S_P[0] & S_P[1] + 预测序列号 + 预测代际 gen_P<br/><br/>*** 序列号方案 (Uint32 代际复合) ***<br/>seq = (代际 << 16) | (循环计数 & 0xFFFF)

    Note over Hardware, GPU: === 第一阶段：输入捕获 ===
    loop 每 1ms 硬件信号
        Hardware->>Kernel: 推送原始增量位移
        Kernel->>Kernel: 内核级队列缓存
    end

    Note over Hardware, GPU: === 第二阶段：帧起始 —— 完整输入提取 (无上限) ===
    Main->>Main: 记录 lastFrameTime, now = performance.now()
    Main->>Main: rawDt = now - lastFrameTime (无截断)
    Main->>Kernel: 提取自 lastFrameTime 以来的**所有**未取输入 (无上限)
    Kernel-->>Main: 全部原始信号
    Main->>Main: 清洗、合并、限幅(操作本身)
    Main->>SharedMem: Atomics.add(输入槽, 总增量)  *** BigInt64 饱和保护,绝不丢 ***

    Note over Main: 渲染帧间隔仅用于预测步长<br/>Δt = min(rawDt, 50ms)

    Note over Hardware, GPU: === 第三阶段：权威/预测双源决策 (零等待) ===
    Main->>SharedMem: 【决策点 1】acquire 读取 V_A + gen_A
    alt V_A 已刷新 (权威就绪)
        Note over Main: 路径 A: 使用最新权威真值
        Main->>SharedMem: 根据 (V_A-1)&1 选择双缓冲槽
        Main->>SharedMem: acquire 读取完整状态 S_new (无撕裂)
        Main->>Local: S_used ← S_new

        Main->>SharedMem: release 更新 Worker-B 基线为 S_new + gen_A + Atomics.notify
        Note over Main: 不操作预测序列号 (避免竞争, Worker-B 自检 gen 失效)
        Main->>Local: 本地记录 gen_used = gen_A
        Main->>Local: 连续预测计数器置 0

    else V_A 未变 (权威未更新)
        Note over Main: 路径 B: 尝试消费预测
        Main->>SharedMem: acquire 读取预测序列号 + gen_P
        Main->>Local: 连续预测计数器 +1
        alt 连续预测 <= 3 且 gen_P == gen_A (预测基于当前代际且未滥用)
            Main->>SharedMem: 根据 (seq_P-1)&1 选择预测双缓冲槽
            Main->>SharedMem: acquire 读取预测状态 S_pred (无撕裂)
            Main->>Local: S_used ← S_pred
            Main->>Local: 更新本地 seq 记录
        else 预测无效/超限/代际不匹配
            Main->>Local: S_used ← S_last (回退上一帧权威)
            Main->>Local: 连续预测计数器置 0
        end
    end

    Note over Main: S_used 确定，进入零等待渲染

    Note over Hardware, GPU: === 第四阶段：异步预测预计算 (管线填充) ===
    Main->>WorkerB: 非阻塞唤醒 (Atomics.notify)
    activate WorkerB
    par 主线程并行 (立即渲染)
        Main->>Main: 基于 S_used 构建渲染命令
        Main->>Main: 视锥体裁剪 & 阴影贴图 & Draw Calls
    and Worker-B 后台微步 (为下一帧服务)
        WorkerB->>SharedMem: acquire 读取最新输入 & 权威 gen_A
        WorkerB->>WorkerB: 若 gen_A 与上次预测使用的不同, 放弃旧计算
        WorkerB->>WorkerB: 预测步长 = min(now - last_physics_time, 16.67ms)
        WorkerB->>WorkerB: 轻量物理微步 (基于动态步长)
        WorkerB->>WorkerB: 生成新 seq (代际复合)
        WorkerB->>SharedMem: 写入预测结果到双缓冲槽 (seq_P&1)
        WorkerB->>SharedMem: release 写入 gen_P = gen_A + seq_P
        Note over WorkerB: 仅当预测基于当前 gen 时才发布
    end
    deactivate WorkerB

    Note over Hardware, GPU: === 第五阶段：GPU 提交 ===
    Main->>GPU: 提交所有渲染指令 (基于 S_used)
    GPU->>GPU: 光栅化 & 像素处理
    GPU-->>Main: 渲染完成

    Note over Hardware, GPU: === 第六阶段：权威物理 (绝对准确性) ===
    loop 固定 64Hz (独立时钟，EMA 滤波可选)
        Note over WorkerA: *** CAS 安全消耗 (防穿墙) ***
        WorkerA->>WorkerA: maxStep = MAX_INPUT_PER_STEP
        loop 原子 CAS 循环
            WorkerA->>SharedMem: cur = Atomics.load(输入槽)
            WorkerA->>WorkerA: 本步消耗量 = min(cur, maxStep)
            WorkerA->>SharedMem: CAS: cur → cur - 本步消耗量
        end
        WorkerA->>WorkerA: 基于消耗量执行完整物理步进
        WorkerA->>SharedMem: 写入状态到双缓冲槽 (V_A&1)
        WorkerA->>SharedMem: release 递增 V_A + 记录 gen_A (内存屏障)
        Note over SharedMem: 状态先于版本号可见
    end

    Note over WorkerB: 热待机 (Atomics.wait) 仅限 Worker 调用
    Note over Main: 循环回到第二阶段
