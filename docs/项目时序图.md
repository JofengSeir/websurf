```
sequenceDiagram
    participant Hardware as 硬件层 (1ms 输入)
    participant Kernel as 浏览器内核 (蓄水池)
    participant Main as 主线程 (唯一物理渲染线: BSP解析 + PhysWorld tick + 渲染)
    participant SharedMem as 共享内存 (SAB)
    participant WorkerA as Worker (权威帧计算器: wasm 世界 + 固定步长)
    participant GPU as 图形硬件

    Note over SharedMem: *** 布局与内存序约束 ***<br/>Int32 控制区: V_A (release/acquire) + gen_A + keys + onGround<br/>BigInt64 输入槽: dxAcc/dyAcc 原子累加 (防溢出, 绝不丢)<br/>BigInt64 权威全状态双缓冲 S_A[0] & S_A[1] (10 值/槽: pos/yaw/pitch/vel/eyeHeight/timeMs)<br/><br/>*** 同步内容 (v7) ***<br/>权威全状态: pos + yaw/pitch + vel + eyeHeight + onGround + timeMs<br/>用途: 主线程每帧速度外推校准 (vel_A + a×Δt) + 异常兜底

    Note over Hardware, GPU: === 第一阶段：输入捕获 ===
    loop 每 1ms 硬件信号
        Hardware->>Kernel: 推送原始增量位移
        Kernel->>Kernel: 内核级队列缓存
    end

    Note over Hardware, GPU: === 第二阶段：帧起始 —— 输入提取 (无上限) ===
    Main->>Main: 记录 lastFrameTime, now = performance.now()
    Main->>Kernel: 提取自 lastFrameTime 以来的**所有**未取输入 (无上限)
    Kernel-->>Main: 全部原始信号
    Main->>Main: 清洗、合并、削平 (CLAMP, 不丢弃)
    Main->>Main: **输入层预处理**: 灵敏度乘入角度增量 (物理两端 sensitivity 固定 1)<br/>Q/E 生成等效鼠标量 (yaw_bind_speed/M_YAW × dt, 独立增量不受灵敏度影响)
    Main->>SharedMem: Atomics.add(输入槽, 总增量) + store keys (含 Q/E 等效量)
    Main->>Main: 同一份输入喂给主线程物理输入缓冲 (pendingDx/pendingKeys)

    Note over Hardware, GPU: === 第三阶段：渲染帧 —— 主线程唯一物理线 (rAF, 无上限) ===
    Main->>SharedMem: acquire 读取 V_A
    alt V_A 已刷新 (权威新帧)
        Main->>SharedMem: 根据 (V_A-1)&1 选择双缓冲槽, acquire 读权威全状态
        Main->>Main: 记录 curAuth (只读, 不反写权威) + 权威加速度 a
    end
    Main->>Main: 校准: set_velocity(vel_A + a×(t_now−t_A)) —— 权威速度外推反馈<br/>(位置/角度不覆盖; 角度纯渲染物理输入驱动)
    Main->>Main: wasm tick(dt, keys, dx, dy) —— **完整物理** (碰撞/传送/死亡/reset)
    Main->>Main: 渲染物理状态 (相机 = pos + eyeHeight; 角度 度→弧度)
    Main->>GPU: 提交渲染指令
    GPU->>GPU: 光栅化 & 像素处理
    GPU-->>Main: 渲染完成

    Note over Hardware, GPU: === 第四阶段：权威帧计算 (固定步长 = 1/tickRate, 64/128Hz 可调) ===
    loop 自驱循环 (setTimeout 4ms 轮询; 固定步长累积器无封顶, 不丢物理时间)
        WorkerA->>SharedMem: exchange 消耗输入 (maxStep 防穿墙, 随步长缩放)
        WorkerA->>WorkerA: wasm tick (完整物理: 碰撞/传送/死亡; 独立权威演化)
        WorkerA->>WorkerA: 碰撞事件检测 (落地上升沿 / 撞墙速度骤降+位移受阻)
        WorkerA->>SharedMem: 写权威全状态到双缓冲槽 (V_A&1)
        WorkerA->>SharedMem: release 递增 V_A + gen_A (内存屏障)
        Note over SharedMem: 状态先于版本号可见
    end

    Note over Hardware, GPU: === 第五阶段：权威碰撞事件回传 (低频, 位置微调+角度同步) ===
    WorkerA-->>Main: phys-event (land/blocked: pos + yawDeg/pitchDeg)
    Main->>Main: 渲染位置与权威差 <60 → set_state 微调 (含权威角度)<br/>差 ≥60 → 跳过防跳变 (异常由 >200 兜底)

    Note over Hardware, GPU: === 第六阶段：位置突变事件 (respawn / teleport) ===
    Main->>WorkerA: respawn / teleport 消息 (双端同执行)
    WorkerA-->>Main: player-respawn (pos + yawDeg 回传一次)
    Main->>Main: 渲染物理 set_state 归零到权威新位置 + 清输入缓冲

    Note over Main: 循环回到第二阶段
```

## 关键设计点（v7）

| 项 | 决策 |
|---|---|
| 物理线 | **主线程 = 唯一物理渲染线**（144Hz 可变 dt，全速无限制）；**Worker = 权威帧计算器**（固定步长 = 1/tickRate，64/128Hz，独立权威演化含地图碰撞） |
| 校准 | 每帧 `set_velocity(vel_A + a×Δt)`（权威速度外推反馈，考虑中途地图碰撞）；**位置/角度不覆盖** |
| 角度 | 纯渲染物理输入驱动（鼠标 + Q/E 输入层化后双端同源）；权威**仅碰撞事件**时同步角度 |
| 输入 | 灵敏度 = 主线程输入层参数（物理两端 sensitivity=1）；Q/E = 输入层等效鼠标量（独立增量，不受灵敏度影响）；双端消费同源输入 → 无分叉 |
| 传送 | 接触计数（地面或斜面 surfing）≥ teleportGateTicks（默认 1 帧）；多点下探探测（0~48）覆盖滑行悬空 gap |
| 参数 | 面板双端同步（Worker 应用 patch + 主线程 renderer）；tickRate 显式传递驱动权威步长 |
