## 0. 结论先行

1. **用户洞见成立且比表面更重要**：64tick 恒速转弯 = 每秒 64 次离散转向，轨迹是 64 边形，单边长度 = |v|/64（速度依赖）。这不是缺陷，是 64t 计算的固有语义；**方案要拟合的正是在 64t 网格上算出来的整条状态序列**。
2. **关键事实：当前两个模式都没有渲染 64t 真实轨迹。** 耦合模式渲染的是 ~144Hz 帧率依赖的可变 dt 预测物理（RM:929,954）；解耦模式渲染的是「1000t 积分的位置 + 64t 注入的速度」混成体（DL:368-372,395）；而真正在 64t 网格上演化出的 tickPhys 位置折线**每 tick 都被算出、然后只取速度、位置被丢弃**（DL:371-372）。单实例 64t + 历史插值是唯一能兑现用户洞见（④）与「忠实反映已算出的物理值」（②）的形态。
3. **surf 边缘异常的机理分界是干净的二分**：凡是「单实例 64t 自己也会产生」的 = 离散化忠实表现（A 类，保留）；凡是「需要第二个实例/校准通道才可能产生」的 = 双实例失真（B 类，消除）。判据：**单实例下该现象在构造上不可能发生**。
4. **单实例固定 tick、零校准方案：理论可行，且是唯一无歧义方案**。代价是一笔明确的、一次性的账：渲染延迟 +1~2 tick（15.6~31.3ms）与 64t 输入量化（忠实语义本身）。边界条件见 §6。
5. 当前两模式的校准交互在压边/出坡/高转速下产生 **7 条可枚举的失真机理**（§2-§4），给出 **6 条可证伪数值恒等式预测**（§5），全部可被下一团队的模拟台复现/否证。

## 1. 正面回应用户洞见：64 边形到底是哪条线的语义

### 1.1 用户洞见的物理表述

- 恒定 yaw 角速度下，64t 每 tick 转向一次：轨迹 = 每 tick 一段直线，方向离散跳变 → 64 边形（转一整圈 360° 用 1s = 64 tick = 64 边）。
- 每 tick 位移 = |v|/64：速度越高单边越长——「单边长短不一」不是 bug，是逐 tick 位移对速度的忠实映射。
- 1000t（1ms）下同样的转弯是 1000 边形，视觉上才近似圆环。
- **推论**：判定一个行为「该不该保留」的标准不是「看起来圆不圆滑」，而是「它是否就是 64t 计算自身的输出」。

## 4. 三场景分歧机理推演（压边 / 出坡 / 高转速）

**S1 压边（骑在坡沿）**：phys 与 tickPhys 位置差 δ（<64u，沿速度向）。当 δ 跨在「坡面（normal.y∈(0.05,0.7)，surfing，空中态）vs 平 lips（normal.y≥0.999，着地态）」分界上：
- tickPhys 落在平 lips 侧：其 64t tick 触发 nopre 钳 250（PL:907-924）或 bhop 落地钳 275（PL:549-557）→ 注入后**渲染中还在坡上的玩家一步掉速 −(v−250)**。
- tickPhys 在坡侧、phys 已滑上平 lips：phys 每 1ms 吃地面摩擦（PL:898）而注入的 tickPhys 速度不含摩擦 → 边界处速度跳升回 tickPhys 值 → 速度面板锯齿（§5-F1）。
- 若 tickPhys 恰在这 15.625ms 里越过坡沿进入空中：注入值带 64t 累积自由落体 vy，而 phys 仍在坡上 → 下一子步 try_player_move 撞坡剪裁 + categorize 投影（PL:815-821）把垂直分量再次改写——**一个窗口内两次互相冲突的垂直修正**。

**S2 出坡（滑离坡沿）**：64t 整步 vs 1ms 累步的离沿时刻天然错位（一整 tick=15.625ms 的相位差）。tickPhys 先离沿：注入的 vy 已在自由落体，phys 还贴坡 → 垂直劈裂；phys 先离沿：tickPhys 仍在坡上，注入 vy≈0 → **B3 月面悬停**：渲染玩家已出坡却以 ≈6.25 u/s 匀速下坠（每窗口 ½·g·tickDt²≈0.098u），直到 δ>64 或 tickPhys 也离沿。这就是「出坡后高度行为不可预测」的第一性来源。

**S3 高转速（500–3500 u/s）**：每 tick 位移 7.8→54.7u。一次碰撞相位错位（两实例对同一几何的撞击 tick 不同）产生的 δ 一次窗口即可达 0.5–0.86 倍 TICK_ANCHOR_DIST(64) → 锚定通道（W3）从「极限操作兜底」变成**常态触发器**：每次触发静默重置 64t 相位（钳制/落地判定相位跳变，CONC:99-101 记录过每边界强锚的连跳崩塌教训）。事件双开（B4）让 teleport/death/blocked 在两实例各自时基上触发：tickPhys 内部 teleport → 单边界 vel=0 注入 → 渲染玩家在非触发点硬停一拍；tickPhys 内部死亡 → respawn 到出生点 → δ>64 → 锚定回拉 → 相位再次重置。

**S4（耦合线补充）trigger_teleport 振荡**：权威先入 trigger → 权威内部传送（MOD:239-258）→ 下一权威帧 dist(render,auth)>500 → C2 反向同步把权威拉回渲染旧位 + 双端输入清空 → 权威再次冲向 trigger……直到渲染侧也入 trigger。表现 = 传送生效延迟 250ms+（冷却 AC:150）+ 期间输入增量被清的二次扰动。坡底传送区是 surf 图标配 → 用户感知的「坡缘意外运动」在耦合线有此独立来源。

## 5. 可证伪数值恒等式预测（供下一团队模拟台逐条复现/否证）

记 v_k = 第 k 边界注入速度，v_phys(k⁻) = 注入前瞬间 phys 的 1kHz S_D 速度，Δ_k = v_k − v_phys(k⁻)。tickDt=1/64=15.625ms。

- **F1（零分歧基线 / 失真指纹）**：无碰撞、无输入、两实例同态时，线性算子按 dt 标定 → Δ_k ≡ 0（浮点噪声级）。**凡是 |Δ_k| 显著非零的边界，必然对应一次双实例状态分歧**（着地态翻转 / 碰撞事件错位 / 输入相位差）。预测数量级：着地态翻转→水平摩擦项 |Δ|≈0.0625·max(v,100)（v=1000 时 ≈62.5 u/s）；碰撞错位→|Δ|≈|v_normal|；输入相位差→小但可测。单实例 64t 下 Δ_k 在构造上不存在。
- **F2（钳制错位）**：平 lips 宽 W、入速 v>250：双实例模式下渲染速度出现**单边界、一步到位**的 v→250（nopre）或 v→275（bhop 落地钳）跳水，且触发时刻与 **tickPhys 的**着地 tick 对齐、与渲染位置过 lips 时刻错开 ≤1 tick；单实例下同型跳水存在（A5/A6）但触发时刻与渲染轨迹严格同步。相关性检验即可证伪/证实 B2。
- **F3（vy 月面钉扎）**：tickPhys 着地 + phys 悬空的窗口内，渲染 vy 每窗口锯齿 0→−12.5 u/s 归零，垂直位移恒 ≈½·800·tickDt²≈0.098 u/窗口（不随时间增长）；单实例自由落体 vy_k=−12.5k 单调增长。数字签名：边界时刻 vy ∈{0,−12.5} 循环。

## 10. t6 立场（r3 之后：预测家族选型的机理判定）

> r3 裁定：Q1 否决 36–43ms，「渲染务必走在 tick 之前」——预测成为必需。前提②自此演进：插值-only 结论被 r3 取代；本文 §1-§8 的判据与 F 系列按 r3 时代扩展后继续作为判分工具。

### 10.1 判分框架：预测正当性四条件（A/B 判据的 r3 扩展）
预测机制无 B 类失真 ⟺ (i) 每个被显示的预测值都是**同源确定性序列的位级未来 tick 值**（非混合、非连续极限曲线）；(ii) 对账重置以**离散 tick 值**为目标（禁止速度混合——混合正是 B1/B8 的签名）；(iii) **游戏态下对账永不触发**（回退计数=0）；(iv) 白名单转换窗（mode_switch/respawn/reset/load/set_params/world_rebuild）允许触发且必须遥测。
**对 premise ⑤ 的正面回应（lockstep 问题的预答）**：家族 1 使「双实例」以 lockstep 镜像形式回归——但两实例间**零写通道**（一方向另一方只读镜像、相等性被活体断言）。按我 §9.2 的锐化假说（rig 上无写入即无因果通道），零写 lockstep 与单实例+校验器因果等价——用户「双物理机制」怀疑的锐化形式（失真=校准写入）被完整继承：预测方案的全部风险恰好就是「不得重新引入任何写入/混合通道」。

### 10.2 家族 1（确定性预测+回退重演）判定：**条件通过，两个 crux**
- **Crux-1 输入台账（单源归属）**：影子与权威若各自从 SAB 消费，逐窗口归属必然错位（相位差 φ 重新分配 delta）——持续甩镜期间每个边界 diff≠0 → 每 tick 回退 = B6 复活（speculated vs consumed 双轨记账），压边场景分支判定随输入错位分叉。**唯一修复**：影子=规范输入消费者（ owns 累加器、边界钳制、写台账环 [tick→dx,dy,mask]），权威 takeInput 改读台账——归属只定义一次，两份 sim 消费同一份。此时预测=**流水线前置计算**（不是猜测）：同 wasm、同台账、同种子 → 位级等。
- **Crux-2 状态完备发布（B5 复活风险）**：影子从权威发布态续算，续算位级等价要求发布**含全部衍生态**（ducked/duck_frac/ground_ticks/contact_ticks/surfing/blocked_ticks/ladder/fall_velocity/landing_velocity/has_jumped_before——我 B5 清单）。现 S_A 布局（pos/yaw/pitch/vel/eyeHeight/timeMs）不完备 → 缺字段即影子续算在首个状态依赖分支分叉 → 回退频发。修复=state_out additive 扩展（bench M4 P2 槽位已预留），发布完备性入 Gate 2 审计。
- **确定性定理**：同 wasm 模块（hash pin）、双实例、同台账、同种子 → 序列位级全等（f64 IEEE 确定；step_core 无墙钟读——teleport 冷却为 tick 制 32 tick；GATE_VETO_COUNT 原子计数不影响物理）。据此 **Δ_k' = v_predicted(k+j) − v_authority(k+j) ≡ 0** 是**活体不变量**（F1 的最强形态：双跑零发散从 rig 测试升格为运行时断言）。
- **回退语义**：游戏态永不触发（crux-1/2 成立时）；触发仅白名单窗——工件=投机尾消失+确认历史冻结 1-2 tick（freeze-then-rebuild），有界、旗标、计数（M5 式）。重置=离散状态替换非混合 → 判据 (ii) 满足。
- **感知延迟账**：输入 t → 影子边界 t_b（≤T）→ 预测 tick 即时算完（wasm ~0.1-0.2ms）→ 下个 rAF 渲染（≤7ms）→ **感知延迟 ≈ 0..15.6ms + ≤7ms ≈ ≤22.6ms（均值 ~11ms）**，对比被否决的 36-43ms 减半；且字面满足「渲染走在 tick 之前」（显示时间越过最后确认 tick，靠投机尾延伸）。
- **事件双通道**：相机结构事件（段断）= 预测 tick 时刻（像素在哪里断就在哪里断）；游戏/UI 事件（teleport 计时/death UI）= 权威确认 tick（预测事件可被转换窗撤销，UI 永不撤发），滞后 ≤1 tick。

### 10.3 队长三问的机理答案
- **③ 重演分支一致性**：台账+完备种子下，重演**就是**权威自身计算的复算（位级同）→ 分叉判定按构造一致，无需单独证明。无台账变体的重演用不同输入 → 压边分叉判定可与权威相异 → 耦合失败类重现 → 拒。
- **② dt 语义对齐**：影子必须 fixedDt=1/64 自跑累加器（I_A_TICK 对齐同一网格时钟），**严禁 rAF 耦合可变 dt**（=耦合线 B8/C4 复活，一票否决）。相位锁定：影子按权威稳定发布相位**投影**下一边界；投影误差 ε → 偶发 +1 tick 输入迟到（有界、遥测、A 类相位语义；3500u/s 下=54.7u 位置差异但双份一致、无发散）。
- **① 压边/出坡/高转速**：零新伪影（条件性）——一致分叉判定（同 sim 同输入）；无 vy 钉扎（不存在 1ms 实例，vy 序列=纯 64t 序列）；无锚定（不存在第二条状态线系，TICK_ANCHOR 机制整体不存在）；高转速唯一敏感点=相位投影 ε 的输入迟到=固有 A 类语义。

### 10.4 家族 2（有界外推）闭式界与判定：**游戏态否决**
- 非接触段闭式上界：|p_true−(p+v·τ)| ≤ ½|a|τ²。|a| 上界：重力 800；水平 air-accel 未钳支路 37500 u/s²（φ>99° 时 binds，PL:291-298）；接地摩擦 |a|≈4v → 位置误差 ≤2·friction·v·τ²。τ=24ms（T+ε 上限）：**worst 10.8u（急转）/ 0.23u（纯重力）/ ~4.0u（3500 接地）**。
- **接触段界 VOID**：外推假设光滑动力学；确认前窗口内发生 blocked/clip/land → 外推过冲至 v·τ（3500×24ms=**84u** 入/穿几何）→ 确认后回弹=耦合吸附（C3）重生，量级更大。**恰在用户痛点场景（压边/出坡）失效** → 判据失败。
- 处置：否决为主动家族；仅允许 ≤1 帧应急兜底（旗标+计数，M5 式）——r3 的「渲染先行」无法由外推安全承载。

### 11.3 ① F4 divergence 解析预判（F2′ 双分支方法论移植）
divergence 主项=**延迟输入窗（T−δ 段）的单 tick 输入相位效应**——sim 函数同一 → 分歧不是混合态伪影，是「输入后缀晚一 tick」的另一条合法轨迹。分解（P-ra-5 S3 应对照）：
- **T1 延迟 yaw/位移输入**：Δyaw ≤ maxStep·(T−δ)/T·M_YAW ≈ 12.8°（δ*=7.6ms）→ 弦位差 ≤|v|T(1−cosΔyaw) ≈1.36u@3500 + 增益错位 ≤0.5u → **bulk div ≤ ~2u**（reviewer div_cap 2-3u 对 bulk 成立）。
- **T2 clip 判定翻转（F2′ 分支 A/B 移植）**：翻转窗≈(bulk div)/|v_n|；翻转时 div≈一 tick 法向响应 ≤|v·n|。
- **T3 落地/step 链翻转（F2′ 分支 3）**：乐观已落地（钳 275+摩擦+投影）vs 修订仍空中 → div 可达 ~26u@2000 + land_punch 相机——**有界但大，罕见**。
- **T4 trigger 穿越翻转**：事件封帽拦住（乐观不发帧、退化直出）→ 显示 div=0；代价=真步事件晚 ≤1 tick=A 类相位语义。
**关键修正：div_cap 2–3u 不能作无条件断言**——T2/T3 翻转 tick 必然击穿。**P-ra-5 应拆双桶**：div_bulk ≤2-3u（非翻转 tick，硬断言）+ div_flip（翻转 tick，独立计数+分支界限值；S3 出翻转率分布；翻转率超阈值→收紧封帽谓词，代价=乐观发布率下降、早窗占比 δ*/T≈49% 收缩——诚实预算上报）。
**封帽规则漏网面实证**：现有封帽谓词=「take_event 非空」只覆盖 T4（事件类）；**T2/T3 接触判定翻转不是事件**——封帽不拦。修复=封帽谓词扩为**状态不连续检测**：take_event 非空 ∨ on_ground 翻转 ∨ blocked_ticks/stuck_ticks 增量 ∨ on_ladder 翻转 ∨ ducked 翻转（全是乐观步后的廉价字段读）→ 把最坏显示弹跳压回 T1 级。S3 验证翻转率（低→谓词实用；高→乐观发布率塌向 F3，预算权衡实测）。
