鼠标与键盘

点击画面锁定鼠标后自由飞行：WASD 平移、空格/C 升降、Shift 加速（×4）、Esc 解锁。

录像回放：K 播放 / 暂停，, / . 逐帧，I / O 设区间 A / B。输入框内这些键不生效。

载入地图与录像

地图：引导层按钮；加载后地图页顶部「更换地图」；或把 .bsp 拖进窗口（换图会重建场景）。地图页底部可开关地面网格与世界坐标轴参考。录像：录像页「选择 JSON 录像…」、拖入 .json（自动切到录像页）、「载入示例录像」；URL 深链 ?bsp=&replay=&rule= 可直接打开配套资源。

规则脚本与播放控制

第三方格式录像：把 .js 转化脚本拖进窗口或在录像页「载入规则脚本」（写法与提示词模板见 docs/replay-rule-ai.md）；深链 ?rule= 同样接受 .js。录像↔地图没对齐时用「变换调整」（平移 / 旋转 yaw / 一键锚定到出生点）。外部脚本可经 window.viewer.replay 控制播放：play / pause / seek(秒) / setSpeed / setMode / follow / tracks()。

起点对齐阈值

录像起点距最近出生点 ≤128 HU 视为已贴合；≥1024 HU 应处理（坐标系映射很可能不对）。修正用录像页「变换调整」分区（一键锚定等）。
